# WoW: Forever
This beta version adds initial support for WoW: Forever!
- Added Gamepad Settings Sync.
- Added Trade (Local) to Chat Channel Manager for WoW: Forever.
- Added syncing Gamepad Specific Edit Mode Layout.
- Added multiple new CVars.

## Additional Changes
- Updated Simplified Chinese translations by nanjuekaien1, thank you!

### Known Issues
- (Forever) Any time Action Bar visibility is changed by this addon, a UI Reload will be required.  This is due to secret taint that occurs when manually refreshing the Action Bar visibility.
    - Due to this, Action Bar visibility syncing is disabled by default in WoW: Forever, but can be enabled. A notice will appear asking you to Reload the interface whenever required.
